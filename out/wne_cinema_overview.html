How to read these animations

  • Only some frames are observations. Filled marker dot = a real satellite composite; hollow dot = a generated in-between frame (the header states how many). Generated frames exist for smooth playback only — never cite them as data.
  • Borrowed months are labelled. Where a month had no usable imagery, gap-fill borrows the same calendar month from another year and the frame says so (e.g. “January 2021 · image from 2023”). The nominal year is kept wherever it has data.
  • Grey / “no data” is honest absence. Masked cloud, shadow and failed thermal retrievals are painted neutral grey (and listed in the legend), never filled in. The one exception is the true-colour set, where clouds are deliberately left visible.
  • Colour scales are fixed per video, so a colour means the same thing in every frame — values are comparable across the whole animation.
  • Reproduce any video with gee-animation --config config/wne_cinema_<name>.yaml — imagery is cached locally, so re-renders skip the downloads.
